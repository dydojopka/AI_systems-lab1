# Изображения онтологий

В основном отчёте используются шесть изображений: дерево Core, дерево Heroes, дерево Items, две ветви Gameplay и дерево связей Player001 с Pudge. PNG подходят для вставки в отчёт, SVG — для увеличения и печати без потери чёткости.

## Происхождение данных

- [sources/ontograf-all.dot](sources/ontograf-all.dot) — исходный DOT-экспорт из OntoGraf 2.0.3 в Protégé 5.6.9 при открытом `Dota2Gameplay.rdf` с локальными импортами. В поле поиска введено `.*`, выбран режим `regexp`, затем выполнен экспорт графа в DOT.
- [sources/ontograf-gameplay.dot](sources/ontograf-gameplay.dot) — отдельный исходный экспорт связей Pudge из активного модуля Gameplay.
- `sources/01-core-tree.dot` — `sources/05-gameplay-buildings-tree.dot` — выбранные из общего экспорта иерархии с добавленным оформлением. Все 57 связей между пользовательскими классами сопоставлены с явными аксиомами `rdfs:subClassOf` четырёх RDF-файлов. Серые узлы обозначают классы, объявленные в Core; цветные — классы рассматриваемого модуля. Два дерева Gameplay содержат все его 20 классов: восемь областей карты и 12 типов сооружений.
- [sources/06-pudge-relations.dot](sources/06-pudge-relations.dot) — фрагмент явно записанных фактов из объединения RDF-файлов. Он дополнен фактами Heroes, поскольку исходный экспорт связей Pudge из активного Gameplay не включает его способности, предмет и роль. Все семь связей и подписи типов проверены по RDF.

Это изображения графов, а не снимки интерфейса редактора. Для размещения узлов деревом и постоянного отображения названий связей использован Graphviz (`dot`). Иерархия и факты онтологий при подготовке иллюстраций не менялись.

`A → B [has subclass]` означает, что B — подкласс A. Так OntoGraf обозначает аксиому `B rdfs:subClassOf A`; `has subclass` не является объектным свойством модели. На последнем рисунке стрелки направлены от субъекта к объекту RDF-утверждения, а подписи `controls`, `hasAbility` и другие являются именами объектных свойств.

## Повторное получение изображений

Чтобы повторно экспортировать исходный граф, открыть `Dota2Gameplay.rdf` в Protégé вместе с `catalog-v001.xml`, включить вкладку OntoGraf, выбрать отображение коротких IRI (**View → Render by entity IRI short name**), найти `.*` в режиме `regexp` и нажать **Export graph to DOT**. Для снимка текущего вида графа на той же панели есть **Export Image**.

Для воспроизведения оформленного дерева из сохранённого DOT-файла в установленном Graphviz:

```shell
dot -Tsvg sources/02-heroes-tree.dot -o 02-heroes-tree.svg
dot -Tpng -Gdpi=192 sources/02-heroes-tree.dot -o 02-heroes-tree.png
```

Аналогично обрабатываются остальные пять оформленных DOT-файлов. Экспорты `ontograf-all.dot` и `ontograf-gameplay.dot` сохранены без изменения как исходные данные, а не как макеты для отчёта.
